  descriptors to `runtime/usb/bos.rs`; transaction state stays in `runtime/webusb.rs`.
  Existing exact-byte fixtures cover BOS, URL and MS OS descriptors across packet
  boundaries; raw tables were not previously untested.
- Remove implicit discovery of CIU tests from core CTest. CIU already registers
  its 30 standalone CTest entries, including the eight USB combinations.
- Read the pinned Cargo channel from `rust-toolchain.toml` in CMake. Shell/CI use
  rustup's directory override; the local Docker image copies that same file.
  The parent's second toolchain file is retained for its standalone toolchain
  probes; it is outside this core-only change.
- Remove unused device/key/TLV declarations and unused C streaming state types.
  Retain native key layout types and the two live filesystem error-injection
  callbacks; grepping only Rust callers would incorrectly classify those as dead.
- Centralize native board, timing, chip, PKE and USB DCD imports in FFI `sys.rs`,
  including one declaration each for delay/tick. Conditional imports retain their
  feature guards. Existing intra-FFI ABI calls/stubs remain separate: these are
  definitions exported by Rust, not duplicated platform implementations. Fixture
  roots explicitly include sys and receive their corresponding feature flags.
  Full generated C/Rust signature verification remains a separate ABI task.
- Derive host image record count from `Record::COUNT`. CIU's count and NDEF IDs
  were already generated by the preceding ABI change; no record format changed.
- Use one strict decimal three-byte version parser for CTAPHID/OATH/PIV. Missing
  environment values still default to development `0.0.0`; malformed supplied
  values now fail the build. Tests include width, component count and syntax errors.
- Share bounded BER tag grammar and definite-length parsing between streaming
  decoding and OpenPGP one-shot headers. Preserve incomplete/invalid status words
  and OpenPGP's narrower tag acceptance. Prefix tests compare both paths.
- Consolidate test dependency discovery, redundant core-normal linkage and OATH
  test indentation. Native host archives use a dedicated no-LTO `host-test`
  profile; firmware release profiles are unchanged. Separate target directories
  remain: sharing a staticlib output path between concurrent feature builds can
  race with consumers even when Cargo serializes compilation.
- Move virtual OpenPGP/PIV shell suites into `tests/hardware`, with explicit
  virtual-card names. Extract portable hardware setup from macOS helpers and use
  it in Linux scripts. Keep OS/tool-specific test sequences. Retain only shUnit2's
  unchanged runtime, license and a provenance note.
- Add enforced Rust formatting, Clippy correctness/suspicious checks and 31
  applet/backend/interface profile checks. Host/std is linted separately from
  standalone FFI's panic handler. Fix the lazy-state macro's unsafe metavariable
  expansion and the ABI generator's duplicate module loading. Explicit adapter
  drops remain allowed because they end borrows before erasure. Style-only
  Clippy lints are not yet enforced. Remove the deleted C `interfaces/` coverage
  filter; existing gcov coverage still measures native C only.

## Measured Storage Experiment, Not Retained

The resident read-pattern finding is valid. A local request-scoped group-header
cache passed the Rust suite, full native integrations and a count/refresh/error
test. For 100 occupied slots, `size/read_at` calls fell from 300 to 150:
25 size queries + 25 header reads + 100 payload reads. The proposed 125-operation
estimate omits one operation per group; a 3-4x device speedup is unsubstantiated.

The initial combined experiment increased NFCC Flash from the previous 183140
bytes to 183460, exceeding the 183296-byte region by 164. Cache representations
and explicit non-inlining still exceeded capacity; forced read inlining was
worse (183748 bytes). TLV changes alone were separately isolated. The cache and
its caller changes were removed; production resident scanning is unchanged.

Next work requires a smaller implementation or measured Flash savings, then
full-store DevKit timings for creation, discovery and credential management,
stack measurements, both product builds and existing corruption/error tests.
`next_rp` remains quadratic; caching a group header does not change its uniqueness
scan complexity. Do not add a full credential/RP cache or retain state across
writes/yields to hide that cost. No hardware speed claim or device flash was made.

## Deferred or Qualified

- `IrqCell`/Generation: worthwhile design work, but a type must account for
  boot-only state, IRQ mailboxes, volatile readers and callbacks outside locks.
  Wrapping all globals in one cell can allow reentrant mutable borrows. Requires
  explicit per-field ownership and reset/preemption tests, plus size/stack checks.
- Registry signatures/macros: workspace differences encode real resource
  ownership. Uniform signatures must preserve leases, feature gates and existing
  no-inline tuning. NFCC has insufficient room for an unmeasured broad rewrite.
- Shared fakes: retain call-order/error-specific fixtures. Extract only proven
  common record behavior after comparing semantics, rather than turning those
  assertions into permissive defaults. Source-import fixtures remain the existing
  Batch 6 migration item; their count alone does not justify deleting coverage.
- Storage defaults: some represent optional unsupported capabilities, not just
  test shortcuts. Mandatory production methods need a capability/backend split;
  removing all defaults would change the public port contract unnecessarily.
- Four staging feature guards: a new cfg-alias build dependency/standalone
  generator configuration is not justified solely by four local guards. Keep
  equivalent feature behavior until capability grouping is addressed.
- Panic-check counts: constant slice bounds often optimize away. `first_chunk`
  also requires proving its Option is present. Compare generated code before
  claiming Flash savings; a mechanical unwrap replacement is not an optimization.
- C formatting is still advisory: enforcing the existing whole-tree check would
  fail on pre-existing native/test formatting and require unrelated mass churn.
  Rust checks added here are enforced. Rust coverage requires its own instrumented
  run rather than treating gcov numbers as Rust coverage.
- Fuzz corpus merging needs the matching instrumented harness and coverage
  evidence. Keep semantic baseline/regression seeds even if a coverage merge
  regards them as duplicates. No unmeasured corpus deletion was made.
