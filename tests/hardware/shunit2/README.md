# shUnit2 runtime

Vendored upstream: https://github.com/kward/shunit2

The retained runtime reports `SHUNIT_VERSION=2.1.9pre`. Its source is unchanged;
the upstream license is in `LICENSE`. Only the single self-contained runtime is
needed by the hardware suites. Upstream examples, framework tests and development
configuration are omitted. Hardware scripts continue sourcing `shunit2/shunit2`.
